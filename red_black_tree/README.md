# Интерактивный конструктор красно-чёрного дерева

Учебный проект по дискретной математике. Визуализирует построение красно-чёрного дерева с пошаговым логированием всех операций балансировки.
Выполнен в группе из
Колеватов Г.А - BE ( и чуть чуть FE ) 
Качура К.М - FE 

Посмотреть работу можно здесь: https://oiwiio.github.io/red_black_tree/

## Запуск

Открыть файл `red_black_tree.html` в браузере — никаких зависимостей и сервера не требуется.

## Возможности

- **Вставка** — введите число в поле и нажмите «Вставить» или Enter
- **Визуализация** — красные и чёрные узлы, золотая подсветка всех узлов, задействованных в последней операции
- **Журнал операций** — каждая вставка раскрывается в цепочку шагов: `insert → recolor → rotate`
- **Статистика** — количество узлов, высота дерева, число красных и чёрных узлов
- **Очистка** — кнопка «Очистить» сбрасывает дерево

## Алгоритм

Реализована классическая вставка в красно-чёрное дерево по Кормену (CLRS):

1. Вставка нового узла как красного
2. Восстановление свойств через `fixInsert`:
   - **Случай 1** — дядя красный → перекраска
   - **Случай 2** — дядя чёрный, узел — «внутренний» ребёнок → поворот
   - **Случай 3** — дядя чёрный, узел — «внешний» ребёнок → перекраска + поворот
